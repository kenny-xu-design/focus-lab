# Decisions

This file records durable project decisions.

## 2026-07-09

- Keep Codex work notes under `docs/` instead of the project root or business code directories.

## 2026-10-18

- 保留 `number-path-memory` 旧路由；在此入口组织基础搜索与进阶记忆，不替换其他训练。
- 使用独立 Web 样式文件，保留当前全局 CSS 中已有的桌面模块改动。
- 数据保留原 localStorage 键；存储结构升级至 3，不改变产品 0.1.0 版本。旧记录无可靠身份/规则元数据，不补算新曲线。
- 本地档案 ID 与浏览器安装 ID 为随机应用 ID，不是硬件/实名身份；跨设备长期记录采用未来经认证的账号 ID。
- 曲线按安装、模式、尺寸、规则、显示环境与新题条件比较；百分比只是任务用时变化。
- Cloudflare 现阶段只做方案评估；未来云同步、研究和模型训练分别授权，不把 Web Analytics 当作训练数据库。
- 学习拓展保留四种方法的说明与研究来源；只为主动回忆和位置联想增加交互，正念复用呼吸训练，间隔复习暂为指南。
- 手机 Web 优先，导航全部直接可见；按用户后续要求移除开发预览栏及 iframe，设备预览交给浏览器原生工具。
- 拓展回忆练习只持久化数量和用时；不保存材料与答案，不把词条成绩混入数字训练曲线。
- 手机和电脑统一使用可安装 PWA，启动入口 `/launcher`，保留 `/popup` 及 manifest 身份 `/popup`；不另外开发手机原生壳。
- 预缓存清单由实际生产构建生成，包含所有脚本、样式与图标；离线不依赖用户先访问每条训练路线。更新等待旧窗口关闭，避免脚本版本混用；开发环境不注册生产缓存。
- 无原生安装提示的浏览器提供手动指引，支持 Safari 主屏幕／程序坞流程；不得以用户接受安装提示就声称系统已安装。
