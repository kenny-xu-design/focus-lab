二、修改后的总体原则

1. 保留现有网站功能、训练页、记录页、PWA 和路由结构。
2. 桌面端是任务与番茄主入口；网站保留为工具箱、记录复盘和降级入口。
3. 当前不再优先增强网站内番茄浮窗。
4. 不做社交自习室、好友系统、排行榜、聊天室。
5. 不做账号系统、云同步、WebDAV、微信小程序、Electron。
6. 新功能必须按模块拆分，避免堆进单个 React 组件。
7. 任务模型、番茄模型、存储模型优先抽象为可复用模块。
8. 第一版只做本地数据，不接远程数据库。
9. 每个阶段必须保留 npm run build 验证。
10. Tauri 相关阶段必须明确区分：
    - 前端构建是否通过
    - Tauri CLI 是否可用
